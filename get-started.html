Начало работы

Добро пожаловать в Quark Engine. Следуйте этой инструкции, чтобы запустить свой первый проект за считанные минуты.

1. Загрузка движка

Перейдите в раздел GitHub Actions или релизы и скачайте последнюю сборку для вашей ОС (Windows или Linux).

Скачать последнюю версию

2. Системные требования

Видеокарта

Поддержка OpenGL 3.3 или выше (NVIDIA GTX 550 / AMD RX 560+).

Компилятор

Для разработки плагинов потребуется MSVC (Visual Studio 2022) или GCC 11+.

3. Создание проекта

После запуска QuarkEditor.exe выберите «New Project». Движок создаст базовую структуру папок:

/MyProject
  /resources         // Текстуры, модели, звуки
  scene.json         // Сохранённая сцена
  project.quarkproj  // Файл конфигурации
Совет: Если вы планируете писать плагины на C++, обязательно загляните в раздел API Документации, чтобы узнать, как взаимодействовать с объектами сцены.
